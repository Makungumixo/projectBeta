Optimisation explorer

Minimise f(x) = 0.12x² + sin(3x), on −5 ≤ x ≤ 5. The curve is a demonstration objective, not a reported coursework result.

How the methods differ

Gradient descent uses the derivative. Hill climbing accepts improvements from neighbouring candidates. Simulated annealing can accept worse candidates as temperature decreases. The genetic algorithm uses a population, selection, crossover and mutation. The genetic algorithm uses the starting x as one initial candidate.
