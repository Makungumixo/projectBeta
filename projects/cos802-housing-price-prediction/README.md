# COS 802 — Ames Housing Price Prediction

**Project:** Predicting residential housing prices with structured-data machine learning  
**Course:** COS 802  
**Evidence status:** Portfolio overview. Source notebook, report and final evaluation metrics pending verification.

## Overview

This project investigates the relationship between housing characteristics and sale prices using the Ames Housing dataset. It is presented as an applied machine-learning workflow rather than a deployed real-estate pricing service.

## Research and modelling workflow

- Explore data distributions, missing values and target-variable patterns.
- Prepare numeric and categorical housing features for regression.
- Evaluate feature engineering and regression modelling choices.
- Compare model performance using an appropriate held-out evaluation protocol.

## Limitations

The Ames housing dataset describes properties from one location and historical period. Performance on its held-out split does not establish generalisability to different housing markets, economic conditions or future periods.
